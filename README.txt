 COMO EXECUTAR O DASHBOARD


OPÇÃO 1 - RECOMENDADA:
1. Abra o terminal/prompt na pasta do projeto
2. Digite: python dashboard_launcher.py
3. Aguarde o navegador abrir automaticamente

OPÇÃO 2 - STREAMLIT DIRETO:
1. Digite: streamlit run dashboard_ips.py
2. Abra http://localhost:8501 no navegador

 ARQUIVOS DO PROJETO


EXECUTÁVEIS:
• dashboard_launcher.py     → Launcher completo (recomendado)

 FUNCIONALIDADES DO DASHBOARD


PÁGINA 1 - VISÃO GERAL:
• Estatísticas descritivas gerais
• Distribuição do IPS por estados
• Top 10 melhores e piores municípios

PÁGINA 2 - ANÁLISE POR ESTADO:
• Filtro por estado específico
• Ranking de municípios por estado
• Comparação com média nacional

PÁGINA 3 - ANÁLISE POR REGIÃO:
• Comparação entre regiões brasileiras
• Distribuição do IPS por região
• Análise estatística regional

PÁGINA 4 - COMPARAÇÃO CAPITAL X INTERIOR:
• Análise específica capitais vs interior
• Testes estatísticos de diferença
• Visualizações comparativas

PÁGINA 5 - INSIGHTS AVANÇADOS:
• Correlações entre variáveis
• Análises de tendências
• Descobertas estatísticas

 REQUISITOS TÉCNICOS


PYTHON: 3.7 ou superior
BIBLIOTECAS:
• streamlit
• plotly
• pandas

O projeto utiliza dados reais do IPS (Índice de Progresso 
Social) do Brasil 2024, fornecendo insights sobre o 
desenvolvimento social dos municípios brasileiros.
